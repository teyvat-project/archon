# Archon M7（Ruby）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ruby 3.2+（CRuby）言語プラグインと、標準ライブラリだけに依存する手書き Ruby ランタイムを実装する。`edge-cases.yaml` と `natsuneko.json` から生成した Ruby SDK が全ファイル `ruby -c` を通り、`rbs validate` が通り、`require` で読み込め、TypeScript / C# / Kotlin / Go と同じ E2E シナリオがモックサーバに対して通ることを完了条件とする。

**Architecture:** `runtimes/ruby` に手書きランタイム（`src/core.rb` ローダーと `src/core/*.rb`、RBS は `src/core.rbs`、テストは `test/*_test.rb`）を置く。ランタイムのソースは compact 形式の `module Archon::Core` で書き、生成時に `Archon::Core` を `<Module>::Core` に置換して出力先 `lib/<gem>/core.rb` / `lib/<gem>/core/` / `sig/<gem>/core.rbs` へコピーする（同じプロセスに複数の生成 SDK を読み込んでも衝突しない）。Ruby プラグイン（`packages/archon/src/plugins/ruby`）は inline の object / enum / union を巻き上げた IR から、モデル（`lib/<gem>/models/<snake>.rb`）、タグ別サービス（`lib/<gem>/services/<snake>.rb`）、`client.rb` / `auth.rb`、エントリ `lib/<gem>.rb`、`<gem>.gemspec`、RBS（`sig/<gem>.rbs`）を出力する。E2E は既存の `e2e/mock-server` を Node スクリプトで起動し、生成 SDK を `$LOAD_PATH` に足した minitest スイート `e2e/ruby` を実行する。

**Tech Stack:** Ruby 3.2+（開発機は Ruby 4.0。CI は 3.2 と最新安定版の両方でランタイムを検証）、minitest（Ruby の bundled gem）、rbs（compile テストのみ）、既存の Node 24 / pnpm 10 / vitest / jiti。

**Spec:** `docs/superpowers/specs/2026-10-25-archon-design.md`（§6 生成 SDK 共通仕様、§7 Ruby 列、§8 認証、§10 テスト戦略）。挙動の規則は M2 / M3 / M6 と同じものを Ruby に写し、ここでは差分だけを書く。

## Global Constraints

- 生成 SDK とランタイムの依存は Ruby 標準ライブラリのみ（`net/http`、`json`、`uri`、`time`、`date`、`securerandom`）。`base64` は 3.4 で bundled gem になったので使わず `pack('m0')` で書く。Ruby 3.2 より新しい API（`it`、`Data#with` 以外の 3.3+ の追加）は使わない（CI の 3.2 ジョブで保証）。全ファイル `# frozen_string_literal: true`。
- API 形状（spec §7）: `client.echo.echo_path_styles(simple: [...], label: [...], matrix: ...)`。パラメータはキーワード引数（必須は必須キーワード、任意は既定 `nil`）、body は先頭の位置引数（任意なら既定 `nil`）、最後に `request_options: nil`。戻り値はデコード済みの値、非 2xx は `ApiError` を raise。
- Middleware（spec §6.2）: `call(request, context, next_)` に応答するオブジェクト（lambda 可）。登録順に外側から実行し、認証適用は最内側。
- 型対応（spec §7 Ruby 列）: `date-time` → `Time`、`date` → `Date`、`int64` → `Integer`、`uuid` / `uri` → `String`、nullable / optional → `nil` 許容（キーワード引数既定 `nil`）。number は `Float`（読み込み時に `to_f`）。
- モデルは `Data.define` の不変値オブジェクト（`from_json` / `to_h`、未知フィールドは無視）。判別あり union → タグで振り分ける `from_json` を持つ module（未知タグは `Core::Unknown`）、判別なし union → 順に試す、enum → 定数を持つ module（値は生の `String` / `Integer`）。予約語は末尾 `_`。
- 標準 middleware・認証・OAuth2・リダイレクト時の資格情報除去・再送可能リクエスト・パラメータ直列化（バイト単位）の規則と既定値は TS / C# / Kotlin / Go と同一。
- requestBody の media type 優先順は json > multipart > form > text > binary（IR で並べ替え済み、`contents[0]` を採用）。
- 生成物の各 `.rb` ファイル先頭は `# frozen_string_literal: true`、空行、生成ヘッダ（`# Code generated by Archon. DO NOT EDIT.` と `output.header`）。

## Spec からの M7 における意図的な差分

- **生成コードは標準の定数を `::` で書く**: スキーマ `String` / `Time` / `Data` / `File` を `<Module>::String` 等としてそのまま出すため、生成コードと生成 RBS は `::String`、`::Data.define` のように書く。ランタイムは compact 形式（`module X::Core`）なので `<Module>` 直下の定数に影響されない。`Core` / `Client` / `Auth` / `VERSION` / `ApiError` / `TransportError` / `TimeoutError` / `DecodeError` / `AuthError` / サービスクラスは予約し、衝突するスキーマには接尾辞を付ける。
- **モデル**: `Echo = ::Data.define(:method_, ...)` の後に `class Echo` を開き、`include Core::Model`、既定値付きの `initialize`（任意は `nil`）、JSON フィールド表（`json_fields Core::Field.new(:method_, 'method', Core::Types::STRING, required: true), ...`）を書く。`from_json(json)`（Hash または JSON 文字列）は必須の欠落・null と型の不一致を `Core::DecodeError` にし、`to_h` / `as_json` はワイヤ名をキーにした JSON の値（`Time` は ISO 8601、`Date` は `YYYY-MM-DD`、`format: byte` は base64）を返す（任意の `nil` は書かない）。`to_json` もある。他のモデルへの参照は `-> { Node }` で遅延させる（自己参照・相互参照・読み込み順に依存しない）。
- **union の値はバリアントそのもの**: 判別ありの `Shape.from_json` は `Circle` / `Square` のインスタンスか `Core::Unknown`（`raw` に JSON を保持し、書き込み時はそのまま返す）を返す。判別プロパティの値が 1 つに決まるバリアントは、`initialize` でそのタグを既定値にする（`Circle.new(radius: 5)` で `kind: 'circle'`）。判別なし union は宣言順に試し、どれにも当たらなければ `Core::Unknown`。循環する判別なし union は Go と同じく平坦化する。
- **enum**: `module Status` に `ACTIVE = 'active'` などの定数、`VALUES`、`known?(value)`。値は生のまま保持・再送できる（spec §6.6）。
- **引数の Hash 受け付け**: object モデル型の引数（body・パラメータ）は、モデルのインスタンスか、そのキーワード引数の Hash（`{ name: 'x', count: 1 }`）を受け付ける（`Model.coerce`）。
- **レスポンスの取得はブロック**: 操作メソッドはブロックを受け取り、成功時に `Core::Response`（`status` / `headers` / `body` / `url`、リダイレクト後の最終 URL）を渡す。非 2xx では `ApiError#response` で取れる。空 body（204 / 205 / 304 / 長さ 0）の JSON は `nil`。
- **エラー型**: `Core::Error < StandardError` を基底に `ApiError`（`status` / `headers` / `raw_body` / `url` / `body`（宣言された型でデコードしたもの、無ければ `nil`）/ `decode_error` / `response`）、`TransportError`（`cause` は元の例外）と `TimeoutError < TransportError`、`DecodeError`（`status` / `raw_body`）、`AuthError`（`schemes`）。生成 SDK の直下にも別名（`EdgeCases::ApiError` など）を置く。
- **キャンセルは無い**: Ruby の同期 API には CallContext のキャンセルトークンが無い（スレッドを止めるのは呼び出し側の責務）。`timeout` は接続・各ソケット読み書きを残り時間で制限し、最終レスポンスまでの期限超過を `TimeoutError` にする。
- **transport は 1 往復の callable**: `transport.call(request, timeout:)` が `Core::Response` を返す。既定は `Core::NetHttpTransport`（リクエストごとに接続、`configure: ->(http) { ... }` でクライアント証明書などを設定）。リダイレクト（手動、cross-origin で資格情報を外す）、タイムアウトの期限、OAuth2 のトークン取得はランタイムが transport を使って行う。
- **資格情報の形**: bearer / API キーは `String` か `call` に応答するもの（毎回呼ぶ）、basic は `Core::Basic.new(username:, password:)` か `{ username:, password: }` かそれを返す callable、oauth2 / openIdConnect は `Core::OAuth2.new(access_token:, client_credentials:, refresh_token:)` か同じキーの Hash。`Auth` は可変（`auth.bearer_auth = 'new'` は次の送信から使われ、OAuth2 の値を差し替えるとトークンマネージャを作り直す）。
- **ヘッダは `Core::Headers`**（大文字小文字を区別しない、`[]` は最初の値、`values` で全部）。Net::HTTP は送信時にヘッダ名を正規化する。

## Review Focus

- **Net::HTTP による URL の書き換え**（query `piped=1|2&filter[a]=b&x=%41`、path の `%2F` / `%41`）→ リクエスト行がランタイムの直列化結果とバイト単位で一致する。→ Task 2 のテスト（生の TCP サーバで記録）。
- **Net::HTTP の既定値**（body があるときの `Content-Type: application/x-www-form-urlencoded`、`Accept: */*`、`User-Agent: Ruby`）→ ランタイムの値で上書きされる。→ Task 2。
- **Ruby の識別子として不正・衝突する名前**（プロパティ `x-foo` / `2fa` / `class` / `method` / `end` / `foo_bar` と `fooBar`、スキーマ `1Thing` / `Client` / `Core` / `String` / `Data`、group `core` / `use`、enum 値 `''` / `-1` / `0.5`）→ 正規化・接尾辞で `ruby -c` と読み込みと `rbs validate` が通る。→ Task 5、Task 7（stress）。
- **自己参照 / 相互参照と循環 union**（`Node.children: [Node]`、`U1 = U2 | string` / `U2 = U1 | int`）→ 読み込みが無限再帰しない。→ Task 5、Task 7。
- **同時リクエスト**（コールドクライアントで 5 スレッド）→ トークン取得は 1 回。→ Task 3、E2E。
